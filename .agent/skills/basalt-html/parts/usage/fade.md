# fade

Nothing to write: a scrolling part (tabs, a segment, a code block, a list, a menu, a dialog, a sheet, a pane) fades its content at each edge that hides more, and the module comes with it. A page that needs every word at full contrast sets `data-fades="off"` on `<html>` from a visible control of its own (`document.documentElement.dataset.fades = "off"`); every fade turns off, open popups included.
