# Display candidates

Geist and Geist Mono stay the UI faces. These three are for brand and editorial moments only.
None is the default. Bailey chooses. All three are SIL Open Font License 1.1 and self-hosted
from `docs/fonts/` (Latin, static woff2). The license files sit beside the fonts.

The review walkthrough's type step sets them in the page. A product that adopts one should
self-host the same files and keep them off UI controls.

| Face | Why it's here | Use it for |
|---|---|---|
| [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) | Sharp, high-contrast, the name already says instrument. Regular and italic. | Case-study titles, a single display line. |
| [Newsreader](https://fonts.google.com/specimen/Newsreader) | A literary text serif, quiet at reading sizes. Regular and semibold. | Long notes, essays, the portfolio's body when it is not UI. |
| [Fraunces](https://fonts.google.com/specimen/Fraunces) | The expressive one: soft, optical, a craft moment. Regular and semibold. | One portfolio headline, not a product UI. |

UI text does not go below 12px. The eyebrow is 12px Geist Mono, uppercase, tracked 0.06em.
A single view should use that eyebrow, 14px UI text, one 24px title, and at most one display size.
