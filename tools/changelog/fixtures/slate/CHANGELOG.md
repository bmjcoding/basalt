## 0.2.0 - 2026-11-16

Slate 0.2.0 adds a composer with mentions and a plate token for highlighted rows. Check existing layout rules and stored data before upgrading.

### Action needed

Before upgrading from 0.1.0, check these 4 changes.

- fillForm: Changed `fillForm` to keep null fields empty, so omit unknown fields or pass `undefined` ([#42](https://github.com/example/slate/pull/42))
- Grid: Changed the parent layout item for `Grid` to `.slate-grid-frame`, where existing sizing rules must move [How to migrate](https://github.com/example/slate/blob/v0.2.0/docs/migrating.md#grid-frame) ([#41](https://github.com/example/slate/pull/41), Linear [SL-112](https://linear.app/example/issue/SL-112), Jira PRJ-88)
- storedCount: Changed stored counts to require an explicit store, so pass `() => localStorage` when reading, writing or clearing old counts [How to migrate](https://github.com/example/slate/blob/v0.2.0/docs/migrating.md#stored-counts) ([#41](https://github.com/example/slate/pull/41))
- TableHeader: Changed fixed `TableHeader` cells to show a supplied `hint`, so remove that prop where a header should stay plain ([#43](https://github.com/example/slate/pull/43))

### Deprecated

- Banner: Deprecated `Banner` in favor of `Notice`, which takes the same props, removed in 1.0.0 no earlier than Mar 1, 2027 ([#44](https://github.com/example/slate/pull/44))

### Added

- Composer: Added `Composer`, a message field that grows from 2 to 8 rows, with Send last and a status line under it ([#45](https://github.com/example/slate/pull/45), Linear [SL-120](https://linear.app/example/issue/SL-120))
- Mention: Added `Mention` to show a name after @ and mark a mention of the reader when `you` is set ([#45](https://github.com/example/slate/pull/45))
- Tokens: Added `--slate-plate` for a highlighted row's solid fill on its current surface level ([#46](https://github.com/example/slate/pull/46), Linear [DS-27](https://linear.app/example/issue/DS-27), Linear [DS-31](https://linear.app/example/issue/DS-31), Jira PRJ-90, GitHub [issue #45](https://github.com/example/slate/issues/45), Linear [SL-131](https://linear.app/example/issue/SL-131))

### Changed

- Toast: Changed toasts on phones to sit 8px below the top bar instead of above the bottom tabs ([#47](https://github.com/example/slate/pull/47))

### Fixed

- Checkbox: Fixed scrolling checkbox lists adding empty space below the page inside a sticky container ([#48](https://github.com/example/slate/pull/48), GitHub [issue #45](https://github.com/example/slate/issues/45))
- Docs: Fixed the contrast table listing secondary ink on the sunken band at 4.1:1, where it measures 4.6:1 ([b703be2f](https://github.com/example/slate/commit/b703be2fcc41217ae7ab767e7987389c3e954f30))
- SelectList: Fixed keyboard focus leaving `SelectList` when the focused row was removed ([#49](https://github.com/example/slate/pull/49))
- Sheet: Fixed clipped focus rings at the top and bottom of a sheet's scrolling body ([#49](https://github.com/example/slate/pull/49))
- Sidebar: Fixed the brand mark sitting off center when the sidebar collapsed to its rail ([#50](https://github.com/example/slate/pull/50))
