# diagram-text

Added for you when a sequence's JSON says `"variant": "text"`.

- The same data as box-drawing characters in a code block, where its widest line fits; elsewhere the transcript (one line a message), which the page holds before script. Nothing scrolls sideways, and the block is hidden from assistive technology: the title, the summary and "View as list" carry it.
- With `"motion": "animated"` it builds by ink: labels and arrows lift in message order, no line hidden, no caret.
