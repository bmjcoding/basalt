# topbar

`.topbar` > `.topbar-inner` (with `.brand`).

The page's one blurred (smoked) surface; it falls back to opaque on its own.

- Once per page.
- Only primary and secondary text goes on it (`.faint` becomes secondary there), a pressed ghost `.btn` takes primary ink, no danger button.
- Don't restyle it, and don't put a second blurred layer on the page.
- It is not printed.
